## 3. 0.1.0 工作包

### R1 配置写入隔离

**目标**：任何页面保存配置时，不得覆盖其他页面的最新修改。

**证据**：`SettingsView.vue:440,757-808`；`LlmConsole.vue:293-311`；`TaskFormModal.vue:771-776`；`commands.rs:48-91`；`core/config.rs:20-27`。

**改造点**：

- 后端 `save_config` 增加 `section` 与 `base_revision` 参数；只合并本段字段，不整包覆盖。
  - `section = "settings"`：除 `llm` 外的设置字段。
  - `section = "llm"`：仅 `llm`。
  - `section = "security"`：仅 `security.allow_commands`（任务弹窗使用）。
- `AppSnapshot` / `ConfigResult` 增加 `configRevision: number`；每次成功保存自增。
- revision 不一致时返回 `[CONFLICT]` 与最新配置，前端只允许“保留我的 / 用磁盘的”二选一，禁止静默覆盖。
- 设置页保存期间继续编辑，保存成功后不得丢弃新编辑。
- 不引入 `ConfigView` / `ConfigPatch` 大重构；`AppConfig` 类型保持不变。

**验收**：

- 设置页改下载目录、AI 页改模型，互不覆盖。
- 冲突时出现二选一对话框；取消不会丢编辑。
- 任务弹窗开启命令执行只改 `security.allow_commands`，不覆盖其他配置。

**测试**：Rust 单测覆盖 section 合并与 revision 冲突；前端 typecheck；手工走查三个保存入口。

**文件边界**：`core/config.rs`、`state.rs`、`commands/config.rs`、`models/config.rs`、`views/SettingsView.vue`、`components/ai/LlmConsole.vue`、`components/tasks/TaskFormModal.vue`、`api.ts`、`types.ts`。

### R2 备份导入安全与恢复事务

**目标**：备份导入按不可信输入处理，不能恢复命令执行能力，不能留下半恢复状态。

**证据**：`backup.rs:72-140`；`commands.rs:340-364`；`SettingsView.vue:734-754`。

**改造点**：

- 导入时强制 `security.allow_commands = false`。
- `command` 类型任务保留命令文本，但 `enabled = false`、`running = false`，并标记“待确认”；不得自动执行。
- 清空 `env`、`extraArgs`、`proxy`、`referer`、`cookiesBrowser`、`last_output`、`last_error`、`last_job_id` 等敏感或运行态字段。
- 限制备份大小、历史条数、任务数、下载记录数；超出直接拒绝。
- 恢复前写入 `restore-backup-<timestamp>/` 快照；使用 `persist::write_bytes` / `save_json` 原子写，失败逐文件回滚。
- AppState 增加 `restoring` 闸门；恢复期间所有写命令返回 `[CONFLICT]`。
- 导入后重载 Scheduler / Downloader 内存状态，避免 tick 用旧快照覆盖恢复结果。
- 后端不再静默自动重启：返回 `ImportOutcome`（含恢复数量、被禁用命令任务数、备份路径），前端弹窗明确展示“已关闭外部命令、N 个命令任务待确认”，由用户点击“重启应用”后再重启。
- 重启后首次快照带 `restoreNotice`，提醒用户检查命令任务。

**验收**：

- canary 备份包含 `allow_commands=true`、已启用命令任务、`env/proxy/cookie/token`：导入后开关为 false、命令任务禁用、敏感字段 0 命中。
- 第 3 个文件写入失败时，前两个文件回滚，原数据字节不变。
- 恢复期间调用保存接口返回 `[CONFLICT]`，不会覆盖恢复结果。
- 导入后 tick 不会把内存旧状态写回磁盘。

**测试**：Rust 临时目录集成测试；失败注入；reload 测试；UI 手工验证弹窗与重启按钮。

**文件边界**：`core/backup.rs`、`commands/backup.rs`、`state.rs`、`scheduler/*`、`downloader/*`、`views/SettingsView.vue`（备份区）、`types.ts`。

### R3 备份 / 诊断导出脱敏

**目标**：默认导出不携带命令、环境变量、输出、Token。

**证据**：`backup.rs:25-64`；`models/task.rs:7-19,57`。

**改造点**：

- 默认导出将 `task.payload.command`、`env`、`last_output`、`last_error`、URL 查询凭据、Header Token 替换为占位符。
- 保留翻译历史正文（用户主动备份的内容，不属于运行凭据）。
- 增加“包含命令与输出（可能含敏感信息）”显式选项；勾选后二次确认。
- 诊断导出复用同一脱敏逻辑，不包含历史正文、密钥、Cookie、代理。
- API：`data_export(include_commands: bool)`；默认 false。

**验收**：

- canary 写入 command/env/output/token 后，默认导出 JSON 0 命中。
- 勾选“包含命令”后 command 命中，但密钥仍不命中。
- 导入脱敏后的备份不报错，任务处于禁用 / 待重填状态。

**测试**：Rust canary 单测；前端 typecheck；手工验证复选框与警告。

**文件边界**：`core/backup.rs`、`commands/backup.rs`、`views/SettingsView.vue`（备份区）、`types.ts`。

### R4 下载凭据不落盘

**目标**：`jobs.json`、事件、快照中不出现代理、Cookie、Referer、额外 Header；重启后可明确重填。

**证据**：`models/download.rs:49-76,78-106`；`downloader/mod.rs:161-194`；`downloader/state.rs:179-205`；`commands.rs:227-230`。

**改造点**：

- 凭据只保存在进程内 `credentials: HashMap<job_id, JobCredentials>`，不进入 `jobs.json`。
- `Job` 增加 `hasCredentials: boolean`（serde default）；列表 / 事件 / 快照中的 referer、proxy、cookies、extraArgs 一律 masked 或空。
- 执行时 worker 从内存凭据表取；持久化前统一剥离。
- 旧 `jobs.json` 迁移：加载时把明文凭据读入内存表，清除后立即原子写回；记录一次迁移提示。
- `job_retry(id, request?)`：内存中无凭据且任务需要凭据时返回 `[CREDENTIALS]`，前端弹出重试对话框，预填本会话输入；重启后任务卡显示“需重填凭据”。
- 不静默失败：错误文案必须明确指向“凭据缺失”，不能显示为普通下载失败。

**验收**：

- 带 proxy/cookie/referer/header 建立任务，`jobs.json`、事件、快照 0 命中 canary。
- 本会话重试成功；重启后重试出现一次点击可完成的重填对话框。
- 迁移后旧明文凭据从磁盘消失。

**测试**：Rust fixture + canary；迁移测试；前端 typecheck；下载 UI 手工验证。

**文件边界**：`models/download.rs`、`core/downloader/*`、`components/download/*`、`views/DownloadView.vue`、`api.ts`、`types.ts`、`store.ts`。

### R5 密钥文件权限与工具校验信任锚

**目标**：不夸大跨平台加密能力；工具安装哈希不能被镜像同时伪造。

**证据**：`secrets/codec.rs:82-90`；`persist.rs:41-57`；`lib.rs:46`；`tools/checksum.rs:109-132`；`tools/net.rs:17-27`。

**改造点**：

- Unix：数据目录 0700，`secrets.bin` 0600；Windows 继续 DPAPI。
- `migrate_inline` 后立即原子写回已清空密钥的 `config.json`；启动时记录一次迁移提示。
- `SecretStatus` 增加平台保护级别（`dpapi` / `file-permissions`）；设置页与 README 明确“macOS/Linux 当前等同明文，勿共享数据目录”。
- 校验文件固定走官方 origin，不随镜像；镜像只用于二进制下载。
- 镜像强制 https；下载大小上限（工具二进制与校验文件分别限制）。
- 官方校验源不可达时 fail-closed：删除临时文件、保留旧版本。
- pinned digest 放 0.2.0，不在本期引入。

**验收**：

- Unix 下数据目录 0700、`secrets.bin` 0600；迁移后 `config.json` 无 canary。
- 模拟镜像返回篡改二进制 + 匹配哈希，安装失败；旧版本仍可用。
- http 镜像被拒绝；超限下载被中止并清理。

**测试**：`cfg(unix)` 权限测试；迁移 canary；URL 选择单测；下载大小限制单测。

**文件边界**：`core/secrets/*`、`core/persist.rs`、`core/tools/*`、`commands/secrets.rs`、`components/ai/KeyManager.vue`、`views/SettingsView.vue`（密钥区）、`README.md`。

### R6 调度器状态 CAS

**目标**：调度 tick、创建、删除、完成回写不会互相覆盖。

**证据**：`engine.rs:149-155`；`task_store.rs:30-35`；`runner/mod.rs:180-228`。

**改造点**：

- `Task` 增加 `revision: u64`（serde default）。
- 所有任务写入走单一 `TaskStore::update` / `Scheduler` 临界区：持 `tasks` 锁完成“修改 → 写盘 → 回写”，或使用 revision CAS 重试。
- `save_and_emit_tasks` 持锁写盘，避免锁外旧快照覆盖。
- revision 与 R1 的配置 revision 使用同一套“期望版本 + 冲突”语义，但各自独立计数。
- 补并发测试：create / delete / finish_run 各 100 次，最终内存与磁盘一致。

**验收**：并发操作后任务不消失、不复活、状态不回退；测试稳定通过。

**文件边界**：`models/task.rs`、`scheduler/task_store.rs`、`scheduler/runner/*`、`types.ts`。

### R7 DB 最小加固

**目标**：SQLite 长查询不卡死；PG 只读不能被 `SET` 绕过；会话不无限累积；切表 / 切库不串结果。

**证据**：`db/mod.rs:161-189`；`db/sqlite.rs:56-102`；`db/postgres.rs:42`；`db/mysql.rs:16-18,44-57`。

**改造点**：

- `DbManager` 会话记录 `openedAt` / `lastUsedAt`；上限 8；30 分钟空闲回收；新增 `db_close_all`。
- SQLite 使用 `progress_handler` 看门狗，15 秒中断并返回 `[TIMEOUT]`；不要用 `busy_timeout` 代替长查询超时。
- PG 使用关键字白名单（复用 MySQL 的 `select/with/values/show/describe/desc/explain`）或每查询 `BEGIN READ ONLY ... ROLLBACK`，禁止 `SET` 绕过。
- 前端 DbView 增加本地 `seq`：open / selectDatabase / query / close 各自递增，过期响应直接丢弃；不改 `dbQuery` 签名。
- TLS、完整事务化只读放 0.1.x。

**验收**：

- 递归 CTE 15 秒超时，连接仍可继续使用。
- 第 9 个会话淘汰最旧会话；30 分钟空闲自动回收。
- `SET default_transaction_read_only=off` 被拒绝。
- 快速切表 / 切库时只显示最后一次请求结果。

**测试**：SQLite 临时库超时测试；会话淘汰单测；SQL 关键字单测；前端 seq 纯函数测试。

## 7. 风险与回滚

| 风险 | 缓解 |
| --- | --- |
| 备份导入失败留下混合数据 | pre-restore 快照 + 原子写 + 逐文件回滚 + 恢复闸门 |
| 下载凭据剥离后重试失败 | 本会话内存保留；重启后明确提示重填；迁移测试 |
| 官方校验源不可达 | fail-closed，保留旧工具版本，提示镜像 / 网络 |
| 调度器持锁写盘阻塞 | 任务上限 ≤50，写盘时间可接受；必要时改单写线程 |
| SQLite 中断后连接不可用 | 中断后重建连接；测试覆盖 |
| 配置 revision 冲突频繁 | 只在保存时检查；冲突对话框二选一，不自动合并 |
| 发版仍用旧产物 | 强制 HEAD 重建；产物时间 / SHA256 校验；checklist |
| 多 Agent 改同一文件 | 文件所有权 + T1 集成 + SettingsView 串行修改 |
