中西文混排

西文 Inter Variable，中文按平台回退：PingFang SC → Microsoft YaHei UI → Noto Sans CJK SC。 保留 text-autospace: normal 自动中西文间距；全局行高 1.6，避免中文回退字体行盒跳动。

字重规则

正文 400；表单标签 / 按钮 / 强调 500；卡片标题 / 激活导航 600；页头 650；展示标题 700。 等宽字体统一 JetBrains Mono → Cascadia Mono → Consolas，仅用于代码、URL、数字列。

优化对照

现有问题 → 设计稿方案

现状问题设计稿方案
图标三套混用：手写内联 SVG、★/☆ 收藏、▸/▾ 展开符统一 SVG sprite：24 网格 / 1.75 描边 / 圆头圆角，收藏与展开改用 star / chevron 图标
字号碎片化：11 / 11.5 / 12 / 12.5 / 13 / 14px 并存收敛为 12 / 13 / 14 / 16 / 20 / 24 六档字阶，按用途取档
标签色硬编码（#4a5265、#333b4d 等）散落各组件全部走语义令牌：--text-2 / --muted / --faint 四级文字色
侧栏 7 项平铺，无分组、无运行状态提示按「常用 / 工具 / 系统」分组，下载 / 任务显示数量徽标，版本号徽标跟随品牌名
状态展示混用 n-tag 与自定义标签，语义色不一致统一 StatusPill：圆点 + 文字，五种语义色，运行中圆点呼吸
高级选项用原生 details，其余用 n-collapse统一折叠面板样式：chevron 旋转指示 + 浅底容器
表格三套：自绘 div 表（数据库 / Key 管理）与 n-data-table统一表格规范：表头浅底 12px、行悬停、NULL 灰斜体、数字列等宽
空状态三套：EmptyState / n-empty / 裸 div统一空状态：36px 线性图标 + 14px 标题 + 12px 描述 + 可选操作
按钮多为纯文字，图标缺失、异步加载态不全按钮统一图标 + 文字，异步操作一律 loading 旋转 + 禁用防重复
页头标题 22px 与卡片标题层级不清页头 20px 带主色图标，卡片标题 13px 次级色，层级一目了然
